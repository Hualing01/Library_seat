# Library Seat Reservation — Interactive Prototype

图书馆阅览座位预约系统 · 高保真交互原型

一个纯前端、零依赖、可离线运行的高保真交互原型，覆盖学生端与管理员端共 18 个页面，
所有按钮、标签、弹层均可点击，形成完整的业务闭环。

## 在线浏览

启用 GitHub Pages 后，访问：

```
https://<你的用户名>.github.io/Library_seat/
```

## 页面构成

学生端 11 个页面：

| 页面 | 说明 |
| --- | --- |
| 登录页 | 学生 / 管理员双角色切换，忘记密码弹窗 |
| 首页 | 座位状态网格（绿=空闲 / 橙=已预约 / 红=使用中），按楼层与阅览室筛选 |
| 座位详情 | 座位属性、可预约时段、签到窗口，可直接发起预约 |
| 预约成功 | 电子凭证样式展示座位、日期、时段、预约编号 |
| 扫码签到 | 30 分钟签到倒计时、进度条、二维码，含签到成功反馈 |
| 我的预约 | 当前预约与历史记录，支持签到、取消、释放、再次预约 |
| 预约历史 | 按已完成 / 已取消 / 违约筛选的时间轴 |
| 违约记录 | 累计违约次数进度与明细，可提交申诉 |
| 提交申诉 | 申诉原因分类与情况说明，含字数校验 |
| 消息通知 | 预约提醒、系统通知、违约提醒三类消息 |
| 个人中心 | 个人信息、统计概览、功能入口、深色模式切换 |

管理员端 7 个页面：

| 页面 | 说明 |
| --- | --- |
| 数据概览 | 四类 KPI 指标、近 7 日预约趋势、座位使用率、热门排行、申诉待办 |
| 座位与阅览室维护 | 座位列表、多条件筛选、新增 / 编辑 / 删除 |
| 座位分布平面图 | 按靠窗 / 中排 / 靠墙排布，可点击座位直接编辑 |
| 全量预约数据 | 按日期、阅览室、状态、关键字筛选，支持导出 |
| 违约申诉处理 | 待处理与全部视图，通过 / 驳回并填写处理意见 |
| 黑名单管理 | 生效中名单、累计违约次数、人工解除 |
| 统计报表 | 预约趋势、时段热度、热门座位排行、学院排行 |

## 直接在原型内跳转

每切换一个页面，浏览器地址栏会自动带上该页标识，复制地址即可直达指定页面：

```
index.html#/page/student-home      学生端首页
index.html#/page/checkin           扫码签到
index.html#/page/admin-appeal      管理员端违约申诉处理
index.html#/page/admin-stats       管理员端统计报表
```

可用页面标识：`login`、`student-home`、`seat-detail`、`booking-success`、`checkin`、
`my-reservation`、`history-list`、`violation-list`、`appeal-submit`、`message-list`、
`profile`、`admin-home`、`admin-seat`、`admin-floorplan`、`admin-reservation`、
`admin-appeal`、`admin-blacklist`、`admin-stats`

原型右下角有一个「页面清单」悬浮按钮，可随时展开全部页面并跳转。

## 本地运行

无需安装任何依赖，直接用 Chrome / Edge 打开 `index.html` 即可。
也可以起一个本地服务：

```bash
python -m http.server 8080
```

然后访问 `http://127.0.0.1:8080/`。

- 原型为纯前端演示，数据为内置示例数据，刷新页面后操作结果会重置。
- 图表由本地 SVG 绘制，不依赖任何 CDN，断网也能完整演示。
